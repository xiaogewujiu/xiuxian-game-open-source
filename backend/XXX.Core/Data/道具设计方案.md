道具系统设计方案

## 背景与目标

道具系统是游戏资源流通的核心，涵盖消耗品、材料、任务物品等多种类型。本方案基于现有道具数据，设计完整的道具分类、使用机制、获取途径和堆叠规则，构建支撑游戏经济系统的道具体系。

## 一、道具系统概览

### 1.1 核心设计原则

| 原则 | 说明 |
|------|------|
| 功能明确 | 每种道具功能单一清晰，避免功能重叠 |
| 获取稳定 | 主要道具有稳定的获取途径 |
| 消耗可控 | 道具消耗与产出平衡，避免通货膨胀 |
| 堆叠优化 | 支持堆叠减少背包压力 |

### 3.2 堆叠规则说明

```
可堆叠条件：
1. 相同道具ID
2. 相同品质（如果有品质差异）
3. 相同绑定状态

不可堆叠情况：
1. 装备类道具
2. 带有唯一标识的道具
3. 不同品质的同名道具
4. 绑定与非绑定道具
```

## 六、道具经济系统

### 6.1 金币产出与消耗

**每日金币产出估算（活跃玩家）**：
```
战斗掉落：约5000-10000金币（根据等级）
任务奖励：约3000-5000金币
出售装备：约2000-5000金币
总计：约10000-20000金币/天
```

**每日金币消耗估算**：
```
药水消耗：约2000-4000金币
强化装备：约5000-20000金币（波动大）
洗练装备：约5000-15000金币（波动大）
商店购买：约2000-5000金币
总计：约14000-44000金币/天
```

**经济平衡**：
- 基础消耗（药水）< 基础产出，保证生存
- 高级消耗（强化洗练）> 产出，需要积累
- 金币不足时可通过出售材料/装备补充

### 8.2 核心算法

```csharp
// 添加道具到背包
public AddItemResult AddItem(int itemId, int count)
{
    var template = GetItemTemplate(itemId);

    // 检查是否可堆叠
    if (template.MaxStack > 1)
    {
        // 寻找已有堆叠
        var existingSlot = FindStackableSlot(itemId);
        if (existingSlot != null)
        {
            int canAdd = Math.Min(count, template.MaxStack - existingSlot.Count);
            existingSlot.Count += canAdd;
            count -= canAdd;

            if (count <= 0)
                return AddItemResult.Success;
        }
    }

    // 需要新格子
    int needSlots = (count + template.MaxStack - 1) / template.MaxStack;
    int emptySlots = GetEmptySlotCount();

    if (emptySlots < needSlots)
        return AddItemResult.InventoryFull;

    // 创建新堆叠
    while (count > 0)
    {
        int stackCount = Math.Min(count, template.MaxStack);
        CreateItemSlot(itemId, stackCount);
        count -= stackCount;
    }

    return AddItemResult.Success;
}

// 使用道具
public UseItemResult UseItem(int slotIndex, int count = 1)
{
    var slot = GetSlot(slotIndex);
    if (slot == null || slot.Count < count)
        return UseItemResult.ItemNotFound;

    var template = GetItemTemplate(slot.ItemId);

    // 检查使用条件
    if (!CheckUseConditions(template))
        return UseItemResult.ConditionNotMet;

    // 执行效果
    for (int i = 0; i < count; i++)
    {
        ApplyItemEffect(template.Effect);
    }

    // 扣除数量
    slot.Count -= count;
    if (slot.Count <= 0)
        RemoveSlot(slotIndex);

    return UseItemResult.Success;
}
```
