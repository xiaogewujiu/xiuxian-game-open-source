丹药系统设计方案

## 背景与目标

丹药系统是玩家属性成长的重要补充，提供永久属性增长和时效战斗增益两种效果。本方案设计完整的丹药分类、使用规则、叠加机制和品质差异，与炼丹系统形成完整的丹药养成线。

## 一、丹药系统概览

### 1.1 核心设计原则

| 原则 | 说明 |
|------|------|
| 永久成长 | 永久属性丹提供可持续的角色成长 |
| 策略选择 | 时效丹药提供战斗策略深度 |
| 使用限制 | 限制使用频率，防止过度依赖 |
| 品质差异 | 不同品质丹药效果差异明显 |

### 1.2 丹药数据结构

```csharp
public class PillTemplate
{
    public int PillId { get; set; }               // 丹药ID
    public string Name { get; set; }              // 丹药名称
    public PillCategory Category { get; set; }    // 丹药分类
    public int Level { get; set; }                // 丹药等级
    public PillEffect Effect { get; set; }        // 丹药效果
    public int Cooldown { get; set; }             // 冷却时间（秒）
    public int DailyLimit { get; set; }           // 每日使用上限
    public int LifetimeLimit { get; set; }        // 终身使用上限
}

public enum PillCategory
{
    Permanent = 1,    // 永久属性丹
    Temporary = 2,    // 时效增益丹
    Functional = 3    // 功能丹药
}

public class PillEffect
{
    public AttributeType Attribute { get; set; }  // 影响属性
    public float Value { get; set; }              // 效果数值
    public bool IsPercentage { get; set; }        // 是否百分比
    public int Duration { get; set; }             // 持续时间（秒，永久丹为0）
}
```

## 三、丹药使用规则

### 3.1 使用条件

| 条件类型 | 说明 | 不满足提示 |
|----------|------|------------|
| 等级限制 | 达到丹药使用等级 | "等级不足，无法使用" |
| 冷却时间 | 不在冷却中 | "冷却中，剩余XX秒" |
| 每日上限 | 未超过每日上限 | "今日使用次数已达上限" |
| 终身上限 | 未超过终身上限 | "此丹药已达服用上限" |
| 状态限制 | 不在特定状态下 | "当前状态无法使用" |

### 3.2 冷却时间机制

```
独立冷却：
- 每种丹药有独立的冷却时间
- 使用A丹药不影响B丹药的使用
- 冷却时间在离线时继续计算

公共冷却（部分丹药）：
- 战斗恢复丹共享冷却
- 避免战斗中连续使用过多恢复道具
```

### 3.3 每日/终身上限重置

```
每日上限：
- 每日0点重置
- 未使用的次数不累积

终身上限：
- 永久累计，不重置
- 达到上限后无法再使用
- VIP可增加部分上限
```

## 四、永久丹药叠加规则

### 4.1 叠加类型

| 叠加方式 | 说明 | 示例 |
|----------|------|------|
| 线性叠加 | 数值直接相加 | 体质丹+5HP，吃10颗+50HP |
| 递减叠加 | 超过阈值后效果递减 | 超过100颗后效果减半 |
| 上限封顶 | 达到上限后不再生效 | 暴击率最高50% |

### 4.2 具体叠加规则

**基础属性丹**：
```
规则：线性叠加，无上限

示例：体质丹
每颗：+5生命值
上限：200颗
最大收益：+1000生命值

对比50级角色基础血量：约5000
贡献比例：20%
```

**高级属性丹**：
```
规则：线性叠加至100颗，之后递减

示例：凝神丹（暴击率）
1-100颗：每颗+0.1%暴击率
101-200颗：每颗+0.05%暴击率

最大收益：100×0.1% + 100×0.05% = 15%
```

**全属性丹**：
```
规则：独立叠加，互不影响

示例：筑基丹 + 结丹丹
筑基丹：全属性+1（100颗上限）
结丹丹：全属性+2（50颗上限）

总收益：全属性+100 + 全属性+100 = 全属性+200
```

### 4.3 永久丹药总收益估算

**满额服用后的总属性增益**：

| 属性 | 丹药增益 | 50级基础属性 | 贡献比例 |
|------|----------|--------------|----------|
| 生命值 | +2000 | 5000 | 40% |
| 物理攻击 | +800 | 1000 | 80% |
| 法术攻击 | +800 | 800 | 100% |
| 物理防御 | +800 | 800 | 100% |
| 法术防御 | +800 | 600 | 133% |
| 速度 | +400 | 300 | 133% |
| 暴击率 | +15% | 基础5% | 大幅提升 |
| 破甲率 | +20% | 基础0% | 全新属性 |

**设计验证**：
```
永久丹药总收益约占角色总属性的30-50%
需要时间积累（预计6-12个月满额）
不会破坏游戏平衡，但提供持续成长感
```

## 五、时效丹药持续时间与效果

### 5.1 持续时间计算

```
基础持续时间 × (1 + 木属性加成)

示例：
经验丹基础持续时间：30分钟
木属性30级加成：15%
实际持续时间：30 × 1.15 = 34.5分钟
```

### 5.2 效果叠加规则

| 叠加类型 | 说明 | 示例 |
|----------|------|------|
| 同种不叠加 | 同种丹药效果取最高 | 狂暴丹不能叠加 |
| 不同种叠加 | 不同效果可同时存在 | 狂暴+金刚可叠加 |
| 药水与丹药 | 时效可叠加，永久取最高 | 攻击药水+狂暴丹 |

### 5.3 时效增益上限

```
同类增益有上限，防止过度堆叠：

攻击类增益上限：+50%
防御类增益上限：+50%
速度类增益上限：+50%
经验类增益上限：+100%
掉率类增益上限：+50%

达到上限后，同类型丹药效果减半
```

## 九、实现方案

```csharp
// 服用丹药
public PillResult TakePill(string playerId, int pillId, int count = 1)
{
    var pill = GetPillTemplate(pillId);
    var data = GetPillData(playerId, pillId);

    // 检查终身上限
    if (data.LifetimeCount + count > pill.LifetimeLimit)
        return PillResult.LifetimeLimitReached;

    // 检查每日上限
    if (data.DailyCount + count > pill.DailyLimit)
        return PillResult.DailyLimitReached;

    // 检查冷却
    if (DateTime.Now < data.NextAvailableTime)
        return PillResult.InCooldown;

    // 应用效果
    for (int i = 0; i < count; i++)
    {
        ApplyPillEffect(playerId, pill);
    }

    // 更新数据
    data.LifetimeCount += count;
    data.DailyCount += count;
    data.NextAvailableTime = DateTime.Now.AddSeconds(pill.Cooldown);

    // 消耗丹药
    ConsumePills(playerId, pillId, count);

    return PillResult.Success;
}

// 应用永久丹药效果
private void ApplyPermanentPill(string playerId, PillTemplate pill)
{
    var player = GetPlayer(playerId);
    float value = pill.Effect.Value * GetQualityMultiplier(pill);

    // 检查递减规则
    if (data.LifetimeCount > 100)
    {
        value *= 0.5f;  // 超过100颗后效果减半
    }

    player.PermanentPillBonuses[pill.Effect.Attribute] += value;
}

// 应用时效丹药效果
private void ApplyTemporaryPill(string playerId, PillTemplate pill)
{
    var effect = new TemporaryEffect
    {
        Attribute = pill.Effect.Attribute,
        Value = pill.Effect.Value * GetQualityMultiplier(pill),
        Duration = pill.Effect.Duration * GetQualityMultiplier(pill),
        StartTime = DateTime.Now
    };

    AddTemporaryEffect(playerId, effect);
}
```

## 十、平衡性验证

### 10.1 永久丹药时间成本

```
假设玩家每天获取丹药：
- 炼丹产出：约10颗/天
- 商店购买：约10颗/天
- 其他途径：约5颗/天

每天总计：约25颗/天

满额200颗需要：8天/种
6种基础属性丹：48天
4种高级属性丹：32天（100颗上限）

总计约3个月可达到主要丹药满额
```

### 10.2 时效丹药经济平衡

```
狂暴丹成本：
- 炼丹成本：约100金币价值材料
- 商店价格：50灵石（约5000金币）
- 效果：攻击+20%，10分钟

对比装备强化收益：
- 强化+1平均成本：约2000金币
- 收益：约5%属性提升

结论：丹药提供临时高性价比增益，但有时间限制，与永久强化形成互补
```
