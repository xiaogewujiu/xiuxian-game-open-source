灵宠系统设计方案

## 背景与目标

灵宠系统是游戏的伴侣养成系统，玩家可以获得、培养灵宠，让灵宠参与战斗辅助玩家。本方案设计灵宠获取途径、属性成长、技能系统和培养机制，构建有趣的宠物养成体验。

## 一、灵宠系统概览

### 1.1 核心设计原则

| 原则 | 说明 |
|------|------|
| 多元获取 | 野外捕捉、副本掉落、商店购买、活动奖励多途径 |
| 成长深度 | 等级、资质、技能多维度培养 |
| 战斗辅助 | 灵宠辅助战斗，但不喧宾夺主 |
| 外观个性 | 不同灵宠有不同外观，满足收集欲 |

## 二、灵宠获取途径

### 2.1 野外捕捉

```
捕捉机制：
1. 特定地图有概率遇到可捕捉灵宠
2. 战斗中使用捕捉道具
3. 成功率受灵宠血量、稀有度影响

捕捉成功率：
血量百分比 × 基础成功率 × 道具加成

基础成功率：
普通：50%
优秀：30%
稀有：15%
史诗：5%
传说：1%
```

**可捕捉灵宠分布**：

| 地图 | 灵宠 | 稀有度 | 出现概率 |
|------|------|--------|----------|
| 新手村 | 小白兔 | 普通 | 20% |
| 迷雾森林 | 树精 | 普通 | 15% |
| 迷雾森林 | 风狼 | 优秀 | 8% |
| 烈焰谷 | 火狐 | 优秀 | 10% |
| 烈焰谷 | 烈焰鸟 | 稀有 | 3% |
| 寒冰洞 | 冰熊 | 稀有 | 5% |
| 五行禁地 | 五行兽 | 史诗 | 1% |

### 2.2 副本掉落

```
副本BOSS有概率掉落宠物蛋
宠物蛋孵化后获得随机灵宠

掉落概率：
普通副本：2%
困难副本：5%
地狱副本：10%

宠物蛋品质：
受副本难度影响，难度越高出好宠物的概率越高
```

### 2.3 商店购买

| 灵宠 | 价格 | 刷新频率 |
|------|------|----------|
| 普通灵宠蛋 | 5000金币 | 常驻 |
| 优秀灵宠蛋 | 20000金币 | 每日刷新 |
| 稀有灵宠蛋 | 500灵石 | 每周刷新 |
| 史诗灵宠蛋 | 2000灵石 | 每月刷新 |

### 2.4 活动奖励

```
限时活动：
- 节日活动：限定外观灵宠
- 登录活动：累计登录送灵宠
- 充值活动：充值达标送传说灵宠

成就奖励：
- 收集成就：收集X种灵宠奖励稀有灵宠
```

## 四、灵宠等级与经验

### 4.1 等级上限

```
灵宠等级 ≤ 玩家等级 + 5

示例：
玩家30级，灵宠最高35级
玩家50级，灵宠最高50级（封顶）
```

### 4.2 经验获取

| 途径 | 经验值 | 说明 |
|------|--------|------|
| 战斗获取 | 怪物的10% | 出战灵宠获得 |
| 经验丹 | 100-1000 | 道具喂养 |
| 灵宠训练 | 50/小时 | 离线挂机获得 |

### 4.3 升级消耗

```
每级所需经验 = 100 × 当前等级

1→2级：100经验
10→11级：1000经验
49→50级：4900经验

总计1→50级：约125000经验
```

## 五、灵宠技能系统

### 5.1 技能类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 普攻技能 | 每回合自动释放 | 爪击、撕咬 |
| 主动技能 | 概率触发 | 火球术、治疗术 |
| 被动技能 | 常驻效果 | 攻击加成、生命恢复 |
| 觉醒技能 | 满级解锁 | 强力大招 |

### 5.2 技能学习

```
升级领悟：
- 每5级有概率领悟新技能
- 稀有度越高，技能池越大

技能书学习：
- 使用技能书学习特定技能
- 技能书副本掉落、商店购买

技能上限：
- 普通：3个技能
- 优秀：4个技能
- 稀有：5个技能
- 史诗：6个技能
- 传说：7个技能
```

### 5.3 技能效果示例

**攻击型技能**：
```
火焰吐息（主动）：
- 概率：30%
- 效果：造成150%攻击力的火焰伤害
- 附加：灼烧效果

狂暴（被动）：
- 效果：攻击+20%
- 生命值低于30%时攻击+50%
```

**防御型技能**：
```
护盾（主动）：
- 概率：25%
- 效果：为主人吸收500伤害

坚韧（被动）：
- 效果：防御+30%
- 受到暴击伤害-50%
```

**辅助型技能**：
```
治疗术（主动）：
- 概率：40%
- 效果：恢复主人20%生命值

激励（被动）：
- 效果：主人攻击+10%
- 主人暴击率+5%
```

## 六、灵宠出战规则

### 6.1 出战数量

```
同时出战：1只灵宠
可拥有数量：上限10只（可扩展）

切换规则：
- 非战斗状态可自由切换
- 战斗状态不可切换
- 每场战斗后可更换
```

### 6.2 出战效果

```
灵宠在战斗中：
1. 每回合自动普攻
2. 概率释放主动技能
3. 被动技能常驻生效
4. 可替主人承受部分伤害（可选）

灵宠属性加成：
- 灵宠30%属性加成到主人
- 传说灵宠50%属性加成到主人
```

### 6.3 灵宠战斗机制

```
灵宠独立血量：
- 灵宠有独立生命值
- 生命值归零后灵宠退场
- 本场战斗不再参与

灵宠不会死亡：
- 战斗结束后灵宠自动恢复
- 需要消耗宠物口粮恢复
```

## 七、灵宠培养

### 7.1 资质洗练

```
消耗：洗髓丹（商店购买、副本掉落）

洗练规则：
- 每次洗练随机改变资质
- 可选择保留原资质或接受新资质
- 洗练次数越多，出现高资质概率越高

洗髓丹价格：50灵石/个
```

### 7.2 进化系统

```
满级后可进化：
- 消耗特定材料
- 进化后等级重置为1
- 属性大幅提升
- 解锁新外观

进化次数：
- 普通：可进化1次
- 优秀：可进化2次
- 稀有：可进化3次
- 史诗：可进化4次
- 传说：可进化5次

每次进化属性+20%
```

### 7.3 亲密度系统

```
亲密度等级：
- 陌生：0-20
- 熟悉：21-50
- 友好：51-80
- 亲密：81-100

提升方式：
- 出战战斗：+1/场
- 喂食口粮：+5/次
- 互动玩耍：+3/次

亲密度效果：
- 友好：属性+5%
- 亲密：属性+10%，解锁特殊动作
```

## 九、实现方案

```csharp
// 灵宠战斗AI
public void PetCombatTurn(PetInstance pet, BattleContext context)
{
    // 普攻
    DealDamage(pet.Stats.Attack);

    // 尝试释放主动技能
    foreach (var skill in pet.Skills.Where(s => s.Type == SkillType.Active))
    {
        if (Random.Range(0f, 1f) < skill.TriggerChance)
        {
            CastSkill(skill, context);
            break; // 每回合最多释放1个主动技能
        }
    }
}

// 计算灵宠战力
public long CalculatePetPower(PetInstance pet)
{
    long power = 0;
    power += pet.Stats.HP * 0.5f;
    power += pet.Stats.Attack * 2;
    power += pet.Stats.Defense * 1;
    power += pet.Stats.Speed * 1.5f;
    power += pet.Skills.Sum(s => s.PowerBonus);
    return power;
}
```

## 十、平衡性验证

### 10.1 战力贡献

```
满级传说灵宠战力：约20000

贡献比例：4%

结论：灵宠提供适度战力加成，不喧宾夺主
```

### 10.2 培养周期

```
获得灵宠到满级：
- 正常培养：约30天
- 加速培养（使用经验丹）：约15天
- 进化满次：额外+60天

总培养周期：约3个月达到完全体
```
