五行聚灵阵设计方案

## 背景与目标

五行聚灵阵是游戏核心养成系统之一，玩家通过收集金木水火土五种属性的材料进行聚灵阵升级，获得对应的属性加成。聚灵阵等级还制约着锻造系统和炼丹系统的等级上限，是整个养成体系的基础。

## 一、聚灵阵系统概览

### 1.1 核心设计原则

| 原则 | 说明 |
|------|------|
| 五行相生 | 金生水、水生木、木生火、火生土、土生金 |
| 循序渐进 | 聚灵阵升级需要大量材料，形成长期追求 |
| 属性加成 | 不同属性提供不同方向的加成 |
| 系统制约 | 聚灵阵等级限制锻造/炼丹等级上限 |

### 1.2 五行属性说明

| 五行 | 代表属性 | 加成方向 | 相关地图 |
|------|----------|----------|----------|
| 金 | 攻击、锐利 | 物理攻击、暴击相关 | 雷鸣峰、金沙遗迹 |
| 木 | 生长、恢复 | 修炼速度、生命恢复 | 迷雾森林、木灵秘境 |
| 水 | 柔和、治愈 | 治疗效果、法力恢复 | 幽暗沼泽、寒冰洞 |
| 火 | 热情、爆发 | 暴击伤害、额外伤害 | 烈焰谷 |
| 土 | 稳固、防御 | 物理防御、法术防御 | 荒芜山脉 |

### 1.3 数据结构

```csharp
public class FiveElementArray
{
    public string PlayerId { get; set; }
    public Dictionary<Element, ElementData> Elements { get; set; }
    public int TotalLevel { get; set; }           // 总等级（所有属性等级之和）
    public int ArrayLevel { get; set; }           // 聚灵阵等级（取最低属性等级）
}

public class ElementData
{
    public Element Type { get; set; }             // 属性类型
    public int Level { get; set; }                // 当前等级
    public int Exp { get; set; }                  // 当前经验
    public List<ElementBonus> Bonuses { get; set; } // 当前加成效果
}

public enum Element
{
    Metal = 1,    // 金
    Wood = 2,     // 木
    Water = 3,    // 水
    Fire = 4,     // 火
    Earth = 5     // 土
}
```

## 二、聚灵阵等级系统

### 2.1 等级上限

| 五行属性 | 独立等级上限 | 聚灵阵总等级上限 |
|----------|--------------|------------------|
| 金 | 50级 | 250级（50×5） |
| 木 | 50级 | 同上 |
| 水 | 50级 | 同上 |
| 火 | 50级 | 同上 |
| 土 | 50级 | 同上 |

### 2.2 聚灵阵等级定义

```
聚灵阵等级 = Min(金等级, 木等级, 水等级, 火等级, 土等级)

示例：
金：30级，木：25级，水：28级，火：32级，土：27级
聚灵阵等级 = 25级（受最低的木等级限制）

设计理念：
- 鼓励玩家平衡发展五行属性
- 避免单一属性过高而其他属性过低
- 体现"五行相生相克"的平衡思想
```

### 2.3 等级阶段划分

| 阶段 | 等级范围 | 阶段名称 | 解锁功能 |
|------|----------|----------|----------|
| 入门 | 1-10级 | 五行入门 | 基础加成 |
| 小成 | 11-20级 | 五行小成 | 锻造/炼丹等级上限+1 |
| 精通 | 21-30级 | 五行精通 | 锻造/炼丹等级上限+2 |
| 大成 | 31-40级 | 五行大成 | 锻造/炼丹等级上限+3 |
| 圆满 | 41-50级 | 五行圆满 | 锻造/炼丹等级上限+5 |

## 三、升级消耗设计

### 3.1 升级经验需求

```
每级经验需求 = 基础经验 × (1 + (等级-1) × 0.1)

基础经验：100
1级→2级：100经验
2级→3级：110经验
3级→4级：120经验
...
49级→50级：580经验

总计1→50级：约15000经验/属性
五行总计：约75000经验
```

### 3.2 材料提供经验

| 材料等级 | 材料名称 | 提供经验 | 获取途径 |
|----------|----------|----------|----------|
| 1级 | 基础材料 | 5经验 | 低级地图掉落 |
| 2级 | 中级材料 | 15经验 | 中级地图掉落 |
| 3级 | 高级材料 | 40经验 | 高级地图掉落、BOSS掉落 |
| 特殊 | 五行精元 | 100经验 | 五行禁地掉落、活动 |

### 3.3 升级材料消耗示例

**从1级升到10级（单属性）**：
```
总经验需求：100+110+120+...+190 = 1450经验
使用1级材料：1450÷5 = 290个
使用2级材料：1450÷15 ≈ 97个
混合使用：约200个1级 + 30个2级
```

**从40级升到50级（单属性）**：
```
总经验需求：490+500+...+580 = 5350经验
使用3级材料：5350÷40 ≈ 134个
使用五行精元：5350÷100 ≈ 54个
```

### 3.4 材料获取效率

```
假设玩家在对应等级地图战斗：
- 每场战斗平均掉落1.5个对应属性材料
- 每天战斗50场
- 每天获得75个材料

升级周期：
1-10级：约4天
10-20级：约8天
20-30级：约12天
30-40级：约16天
40-50级：约20天

单属性50级总计：约60天
五行全部50级：约300天（10个月）

注：可通过活动、购买等方式加速
```

## 五、五行相生相克机制（可选扩展）

### 5.1 相生加成

当五行属性达到一定条件时，激活相生加成：

```
相生关系：
金生水：金等级 ≥ 水等级时，水属性效果+10%
水生木：水等级 ≥ 木等级时，木属性效果+10%
木生火：木等级 ≥ 火等级时，火属性效果+10%
火生土：火等级 ≥ 土等级时，土属性效果+10%
土生金：土等级 ≥ 金等级时，金属性效果+10%
```

**平衡发展奖励**：
```
当五行等级差 ≤ 3级时：
- 所有属性效果+15%
- 额外获得"五行协调"称号

设计理念：
鼓励玩家平衡发展五行，而非单一属性极限堆叠
```

### 5.2 相克机制（PVP向）

在PVP中，五行属性可产生克制效果：

```
相克关系：
金克木：对木属性玩家伤害+10%
木克土：对土属性玩家伤害+10%
土克水：对水属性玩家伤害+10%
水克火：对火属性玩家伤害+10%
火克金：对金属性玩家伤害+10%

玩家主属性判定：
- 取等级最高的五行属性为主属性
- 可消耗道具更改主属性（CD 7天）
```

## 六、聚灵阵与锻造/炼丹的关系

### 6.1 等级上限制约

```
锻造台等级上限 = 聚灵阵等级 + 5

示例：
聚灵阵等级25级
```

### 8.2 核心算法

```csharp
// 计算聚灵阵等级
public int CalculateArrayLevel(FiveElementArray array)
{
    return array.Elements.Values.Min(e => e.Level);
}

// 计算总战力加成
public long CalculateBonusPower(FiveElementArray array)
{
    long power = 0;

    foreach (var element in array.Elements.Values)
    {
        power += CalculateElementBonusPower(element);
    }

    // 应用相生加成
    power = (long)(power * GetXiangShengMultiplier(array));

    return power;
}

// 升级五行属性
public UpgradeResult UpgradeElement(string playerId, Element type, List<Item> materials)
{
    var array = GetArray(playerId);
    var element = array.Elements[type];

    if (element.Level >= 50)
        return UpgradeResult.MaxLevelReached;

    // 计算材料提供的经验
    int totalExp = materials.Sum(m => GetMaterialExp(m));

    // 添加经验
    element.Exp += totalExp;

    // 检查升级
    while (element.Exp >= GetExpRequired(element.Level))
    {
        element.Exp -= GetExpRequired(element.Level);
        element.Level++;

        // 更新属性加成
        UpdateElementBonuses(element);
    }

    // 更新聚灵阵等级
    array.ArrayLevel = CalculateArrayLevel(array);

    // 消耗材料
    ConsumeMaterials(playerId, materials);

    SaveArray(array);

    return UpgradeResult.Success;
}

// 获取锻造/炼丹等级上限
public int GetForgeLevelLimit(string playerId)
{
    var array = GetArray(playerId);
    return array.ArrayLevel + 5;
}
```

## 九、平衡性验证

### 9.1 成长周期验证

```
假设活跃玩家每天投入：
- 时间：2小时
- 战斗：80场
- 材料获取：约120个/天（混合属性）

单属性50级周期：
总需求：约3000个材料
周期：约25天（实际因属性分散会更长）

五行全部50级周期：
总需求：约15000个材料
周期：约125天（4个月）

结论：成长周期合理，提供长期追求，但不会过于漫长
```

### 9.2 战力贡献验证

```
满级聚灵阵战力加成：约100000
50级玩家基础战力：约500000

贡献比例：20%

对比其他系统：
- 装备：约60%（300000）
- 属性点：约15%（75000）
- 聚灵阵：约20%（100000）
- 其他：约5%（25000）

结论：聚灵阵贡献合理，是重要的战力来源但不过度
```

### 9.3 与锻造/炼丹的关系验证

```
聚灵阵30级时：
- 锻造/炼丹等级上限：35级
- 可打造/炼制40级装备/丹药
- 成功率约70%

聚灵阵50级时：
- 锻造/炼丹等级上限：55级（实际受其他限制可能为50级）
- 可打造/炼制50级装备/丹药
- 成功率约85%

结论：聚灵阵提供基础保障，但高等级还需锻造/炼丹师等级配合
```
