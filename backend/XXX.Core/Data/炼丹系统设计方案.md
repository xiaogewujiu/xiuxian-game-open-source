炼丹系统设计方案

## 背景与目标

炼丹系统是玩家自主炼制丹药的核心玩法，通过提升炼丹炉等级和炼丹师等级，玩家可以炼制出更高品质、更强效果的丹药。炼丹等级受五行聚灵阵等级限制，与锻造系统形成平行的养成线。

## 一、炼丹系统概览

### 1.1 核心设计原则

| 原则 | 说明 |
|------|------|
| 等级制约 | 炼丹炉等级 ≤ 聚灵阵等级 + 5 |
| 双轨成长 | 炼丹炉等级 + 炼丹师等级共同影响炼丹效果 |
| 配方学习 | 需要学习丹方才能炼制对应丹药 |
| 品质差异 | 炼丹产出有不同品质，效果差异明显 |

### 1.2 数据结构

```csharp
public class AlchemySystem
{
    public string PlayerId { get; set; }
    public int FurnaceLevel { get; set; }         // 炼丹炉等级
    public int AlchemistLevel { get; set; }       // 炼丹师等级
    public int AlchemistExp { get; set; }         // 炼丹师经验
    public int AlchemyCount { get; set; }         // 累计炼丹次数
    public List<int> LearnedRecipes { get; set; } // 已学丹方
}

public class AlchemyRecipe
{
    public int RecipeId { get; set; }             // 丹方ID
    public string Name { get; set; }              // 丹药名称
    public int MinLevel { get; set; }             // 最低炼丹等级
    public List<AlchemyMaterial> Materials { get; set; } // 所需材料
    public int BaseSuccessRate { get; set; }      // 基础成功率
    public int ProduceCount { get; set; }         // 单次产出数量
}

public class AlchemyResult
{
    public bool Success { get; set; }             // 是否成功
    public Item Item { get; set; }                // 产出的丹药
    public ItemQuality Quality { get; set; }      // 产出品质
    public int Count { get; set; }                // 产出数量
    public int ExpGained { get; set; }            // 获得的经验
}
```

## 五、炼丹成功率公式

### 5.1 基础成功率

```
基础成功率 = 丹药等级基础率 + 炼丹炉加成 + 炼丹师加成 + 五行加成

丹药等级基础率：
1-20级丹药：85%
21-30级丹药：75%
31-40级丹药：65%
41-45级丹药：55%
46-50级丹药：45%

炼丹炉加成：炼丹炉等级 × 0.5%
炼丹师加成：炼丹师等级 × 0.3%
五行加成（木属性）：木属性等级 × 0.2%
```

### 5.2 成功率计算示例

```
场景：炼制35级丹药
- 炼丹炉等级：32级
- 炼丹师等级：28级
- 木属性等级：30级

计算：
基础成功率：65%（35级丹药）
炼丹炉加成：32 × 0.5% = 16%
炼丹师加成：28 × 0.3% = 8.4%
五行加成：30 × 0.2% = 6%

总成功率：65 + 16 + 8.4 + 6 = 95.4% → 95%（上限）
```

## 八、特殊炼丹功能

### 8.1 批量炼丹

```
解锁：炼丹师等级15级

功能：
- 一次炼制多颗相同丹药
- 材料自动计算
- 批量显示结果

限制：
- 一次最多20颗
- 品质独立计算
```

### 8.2 丹药精炼

```
解锁：炼丹师等级35级
消耗：3颗同品质丹药 → 1颗更高品质丹药

成功率：
普通→精品：80%
精品→良品：60%
良品→上品：40%
上品→极品：20%

失败惩罚：损失1颗材料丹药
```

### 8.3 丹药合成

```
解锁：炼丹师等级25级

功能：将低等级丹药合成为高等级丹药
比例：5颗低级 = 1颗高级

示例：
5颗止血丹 = 1颗回春丹
5颗回春丹 = 1颗大还丹
```

## 十、实现方案

```csharp
// 计算炼丹成功率
public float CalculateSuccessRate(AlchemyRecipe recipe, AlchemySystem system)
{
    float baseRate = GetBaseSuccessRate(recipe.MinLevel);
    float furnaceBonus = system.FurnaceLevel * 0.005f;
    float alchemistBonus = system.AlchemistLevel * 0.003f;
    float elementBonus = GetWoodElementLevel(system.PlayerId) * 0.002f;

    float totalRate = baseRate + furnaceBonus + alchemistBonus + elementBonus;
    return Math.Min(totalRate, 0.95f);
}

// 执行炼丹
public AlchemyResult ExecuteAlchemy(AlchemyRecipe recipe, AlchemySystem system, int count = 1)
{
    var result = new AlchemyResult();
    float successRate = CalculateSuccessRate(recipe, system);

    // 判定成功
    bool isSuccess = Random.Range(0f, 1f) < successRate;

    if (isSuccess)
    {
        result.Success = true;
        result.Quality = DetermineQuality(system);
        result.Count = count * GetDoubleProduceChance(system);
        result.Item = GeneratePill(recipe, result.Quality);
        result.ExpGained = GetExpByQuality(result.Quality) * count;
    }
    else
    {
        result.Success = false;
        result.ExpGained = 5 * count;
    }

    AddAlchemistExp(system, result.ExpGained);
    system.AlchemyCount++;

    return result;
}
```

## 十一、平衡性验证

```
假设玩家每天炼丹20次：
- 平均材料消耗：约3000金币（灵田产出为主）
- 失败损失：约500金币
- 产出丹药价值：约5000金币

净收益：约1500金币/天

永久丹药限制：
- 每种永久丹药有服用上限（如最多100颗）
- 防止无限堆叠属性破坏平衡

结论：炼丹系统收益适中，永久丹药有上限控制，不会造成过度膨胀
```
