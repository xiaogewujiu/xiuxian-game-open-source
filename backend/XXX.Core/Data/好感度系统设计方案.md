# 好感度系统设计方案

## 1. 系统概述

好感度系统是玩家之间的社交互动系统，通过赠送道具来增减好感度值。好感度关系双向独立（A→B ≠ B→A），可为负数。

### 核心特性

- 玩家间好感度双向独立
- 好感度可为正数或负数，仅通过道具增减
- 分级制展示，等级后台可配置
- 好感度道具复用现有道具系统，在现有道具管理上扩展
- 每种道具有独立每日赠送上限，零点重置
- 支持离线赠送
- 多入口赠送：背包、好感度面板、聊天/宗门场景

## 2. 数据库设计

### 2.1 新增表 `PlayerFavorability` — 玩家间好感度

| 字段 | 类型 | 说明 |
|------|------|------|
| Id | long (PK, 自增) | 主键 |
| PlayerId | string | 发起方玩家ID |
| TargetPlayerId | string | 目标方玩家ID |
| Value | int | 好感度值（可为负数） |
| TodayGiftJson | string | 当日赠送记录 JSON，格式 `{"itemId":count}`，零点清空 |
| LastGiftTime | DateTime | 最后一次赠送时间 |
| CreatedTime | DateTime | 首次建立关系时间 |

唯一索引：`(PlayerId, TargetPlayerId)`

### 2.2 新增表 `FavorabilityGiftLog` — 赠送日志

| 字段 | 类型 | 说明 |
|------|------|------|
| Id | long (PK, 自增) | 主键 |
| PlayerId | string | 赠送方 |
| TargetPlayerId | string | 收礼方 |
| ItemId | string | 道具ID |
| ItemName | string | 道具名（冗余，方便查询） |
| FavorabilityChange | int | 好感度变化值 |
| GiftTime | DateTime | 赠送时间 |

### 2.3 修改表 `ItemTemplateEntity` — 新增字段

新增 `FavorabilityGiftConfigJson` 字段（string，可空），存储 JSON：

```json
{
  "favorabilityValue": 10,
  "dailyLimit": 5,
  "canGift": true
}
```

- `favorabilityValue`：赠送后增加的好感度值（负数则减少）
- `dailyLimit`：每天对该道具的赠送上限
- `canGift`：是否可赠送

### 2.4 新增表 `FavorabilityLevelConfig` — 好感度等级配置

| 字段 | 类型 | 说明 |
|------|------|------|
| Id | int (PK, 自增) | 主键 |

| MaxValue | int | 最高好感度阈值 |
| Color | string | 显示颜色（hex） |

## 3. 核心逻辑

### 3.1 `FavorabilityManager`（Core 层）

新增 `XXX.Core/Favorability/FavorabilityManager.cs`。

#### 赠送道具 `GiftItem(playerId, targetPlayerId, itemId)`

每次赠送固定消耗 1 个道具，不可批量赠送。

流程：
1. 校验道具是否存在且类型为好感度道具（`FavorabilityGiftConfigJson` 不为空）
2. 校验 `canGift` 是否为 true
3. 校验背包中该道具数量是否 >= 1
4. 校验当日该道具赠送次数是否超过 `dailyLimit`
5. 扣除背包道具 1 个
6. 更新 `PlayerFavorability.Value`（没有记录则创建）
7. 更新 `TodayGiftJson` 中该道具的计数 +1
8. 写入 `FavorabilityGiftLog`
9. 返回结果（含新的好感度值和等级）

#### 获取好感度列表 `GetFavorabilityList(playerId, direction)`

- `direction`：`ToOthers`（我对别人的）/ `FromOthers`（别人对我的）
- 返回列表：对方道号、头像、好感度值、等级名称、等级颜色、最近赠送记录（最近 5 条）

#### 获取赠送记录 `GetGiftLog(playerId, targetPlayerId, pageIndex, pageSize)`

- 分页查询赠送日志

#### 每日重置 `ResetDailyGiftLimits()`

- 零点由后台 HostedService 调用，清空所有 `TodayGiftJson`

#### 获取好感度等级 `GetLevels()`

- 返回所有等级配置，供前端展示

### 3.2 赠送入口统一

无论从哪个入口赠送，最终都调用 `FavorabilityManager.GiftItem()`：

- **背包入口**：在 `InventoryController` 新增 `POST /api/inventory/gift-favorability` 接口，复用 `FavorabilityManager.GiftItem()`
- **好感度面板入口**：在 `FavorabilityController` 新增 `GiftItem` 接口
- **聊天/宗门入口**：点击玩家头像弹出操作菜单，选择"赠送"后复用同一接口

## 4. API 设计

### 4.1 `FavorabilityController`（WebApi 层）

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/favorability/gift` | POST | 赠送好感度道具 |
| `/api/favorability/list` | GET | 获取好感度列表 |
| `/api/favorability/log` | GET | 获取赠送记录 |
| `/api/favorability/levels` | GET | 获取好感度等级配置 |

#### 请求/响应 DTO

**赠送请求** `GiftFavorabilityRequest`：
```json
{
  "targetPlayerId": "xxx",
  "itemId": "item_rose"
}
```

每次赠送固定消耗 1 个道具。

**赠送响应** `GiftFavorabilityResponse`：
```json
{
  "success": true,
  "newValue": 110,
  "levelName": "道友之谊",
  "levelColor": "#4CAF50",
  "message": "赠送成功，好感度+10"
}
```

**好感度列表响应** `FavorabilityListItem`：
```json
{
  "playerId": "xxx",
  "playerName": "道号",
  "avatarPath": "avatar.png",
  "value": 110,
  "levelName": "道友之谊",
  "levelColor": "#4CAF50",
  "lastGiftTime": "2026-06-12T10:00:00",
  "recentGifts": [
    { "itemName": "玫瑰", "change": 10, "time": "2026-06-12T10:00:00" }
  ]
}
```

## 5. 后台管理

### 5.1 好感度关系管理

新增 `AdminFavorabilityController`：

| 接口 | 说明 |
|------|------|
| 查询所有好感度关系 | 支持按玩家名/ID筛选，分页 |
| 修改好感度数值 | 管理员手动调整某对关系的好感度值 |
| 删除好感度关系 | 清除某对关系 |
| 查询赠送记录 | 按时间、玩家、道具筛选，分页 |
| 好感度统计 | 热门好感度排行（被最多人送礼的玩家）、赠送总次数等 |

### 5.2 好感度等级配置管理

后台管理页面新增「好感度等级」模块：

- 列表展示所有等级配置（等级序号、名称、阈值、颜色）
- 支持增删改
- 排序拖拽调整

### 5.3 道具管理页面扩展

在现有道具管理页面中：

- 当道具类型选择为好感度道具时，展开子配置区域：
  - `favorabilityValue`（好感度值，正数增加，负数减少）
  - `dailyLimit`（每日赠送上限）
  - `canGift`（是否可赠送，默认 true）
- 其他道具类型不受影响，子配置区域隐藏

## 6. 前端 UI 设计

### 6.1 好感度面板 — `FavorabilityModal.vue`

新增弹窗，入口在底部栏（BottomBar），包含三个 Tab：

**Tab 1：我对别人的好感度**
- 列表项：头像 + 道号 + 好感度值 + 等级标签（带颜色）
- 每项右侧操作：「查看详情」展开最近赠送记录、「赠送」打开赠送弹窗
- 顶部搜索框：按道号筛选
- 空状态提示

**Tab 2：别人对我的好感度**
- 同样布局，但没有「赠送」按钮
- 只展示头像、道号、好感度值、等级

**Tab 3：赠送记录**
- 时间线样式：谁在什么时间送了什么给我 / 我送了什么给谁
- 分页加载

### 6.2 赠送弹窗 — `GiftFavorabilityModal.vue`

- 标题：「赠送好感度道具给 [玩家道号]」
- 道具列表：只显示背包中 `canGift=true` 的好感度道具
  - 显示图标、名称、数量、每日剩余赠送次数
- 选择道具后显示：将增加/减少多少好感度
- 确认赠送按钮
- 赠送成功后 Toast 提示 + 好感度值动画变化

### 6.3 背包面板扩展

在 `InventoryPanel.vue` 的道具操作区域：
- 当选中的是好感度道具时，操作按钮增加「赠送」
- 点击后弹出玩家搜索/选择界面

### 6.4 聊天/宗门场景扩展

在聊天消息和宗门成员列表中：
- 玩家头像/名称的右键菜单（或长按）增加「赠送好感度道具」选项
- 点击后打开赠送弹窗，目标玩家自动填充

### 6.5 入口位置

好感度面板入口放在底部栏（BottomBar），跟其他功能入口并列。

## 7. 每日重置机制

新增 `FavorabilityResetService`（继承 `BackgroundService` / `IHostedService`）：

- 计算距离下一个零点的时间差
- 到达零点后执行 `FavorabilityManager.ResetDailyGiftLimits()`
- 清空所有 `PlayerFavorability.TodayGiftJson`
- 循环等待下一个零点
