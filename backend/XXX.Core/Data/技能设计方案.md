技能系统设计方案（含技能升级）

## 背景与目标

技能系统是战斗玩法的核心，决定角色的战斗风格和策略选择。本方案基于现有75个技能数据，设计完整的技能升级系统、学习条件、释放策略和多段伤害机制，构建有深度的技能养成体系。

## 一、技能系统概览

### 1.1 核心设计原则

| 原则 | 说明 |
|------|------|
| 流派分化 | 不同武器类型对应不同技能倾向，形成流派差异 |
| 成长感 | 技能可升级，提升数值和效果，提供成长反馈 |
| 策略深度 | 多种释放策略（顺序/随机/智能），不同战斗场景选择 |
| 资源消耗 | 技能升级需要投入资源，形成选择和取舍 |

### 1.2 技能数据结构

```csharp
public class SkillTemplate
{
    public int Id { get; set; }               // 技能ID
    public string Name { get; set; }          // 技能名称
    public string Description { get; set; }   // 技能描述
    public TargetType TargetType { get; set; } // 目标类型（1敌方/2友方）
    public int ManaCost { get; set; }         // 法力消耗
    public int Cooldown { get; set; }         // 冷却回合
    public DamageType DamageType { get; set; } // 伤害类型
    public int HitCount { get; set; }         // 攻击次数
    public RangeType RangeType { get; set; }  // 范围类型（0全体/1单体）
    public float DamageMultiplier { get; set; } // 伤害倍率
    public List<string> BuffIds { get; set; } // Buff效果列表
    public int TriggerChance { get; set; }    // 触发概率
    public int LearnLevel { get; set; }       // 学习等级
    public int MaxLevel { get; set; }         // 最大等级
}

public class SkillInstance
{
    public int SkillId { get; set; }          // 技能ID
    public int CurrentLevel { get; set; }     // 当前等级
    public int CurrentExp { get; set; }       // 当前经验（技能熟练度）
    public bool IsUnlocked { get; set; }      // 是否已解锁
    public CastStrategy Strategy { get; set; } // 释放策略
}

public enum CastStrategy
{
    Sequential = 0,   // 顺序释放
    Random = 1,       // 随机释放
    Smart = 2         // 智能释放（根据场景选择）
}
```

## 五、技能释放策略

### 5.1 释放策略类型

```csharp
public enum CastStrategy
{
    Sequential = 0,   // 顺序释放：按技能栏顺序依次使用
    Random = 1,       // 随机释放：随机选择可用技能
    Smart = 2,        // 智能释放：根据场景选择最优技能
    Priority = 3      // 优先级释放：按优先级使用（扩展）
}
```

### 5.2 顺序释放（Sequential）

**机制**：按技能栏设定的顺序依次使用技能

**适用场景**：
- 固定连招套路
- 自动化战斗
- 新手玩家

**策略配置**：
```
技能栏顺序：
1. 狂暴之力（Buff）
2. 破甲斩（Debuff）
3. 重击（高伤害）
4. 普通攻击（填充）

执行逻辑：
- 按顺序检查技能可用性（冷却、蓝量）
- 可用则释放，不可用则检查下一个
- 都不可用则使用普通攻击
```

### 5.3 随机释放（Random）

**机制**：在可用技能中随机选择一个释放

**适用场景**：
- 测试技能搭配
- 娱乐玩法
- 特定随机流派

**权重配置**：
```
可为每个技能设置权重：
- 高伤害技能：权重5
- 普通技能：权重3
- Buff技能：权重2
- 控制技能：权重1

随机时按权重概率选择
```

### 5.4 智能释放（Smart）

**机制**：根据当前战斗状态智能选择最优技能

**适用场景**：
- 高难度战斗
- PVP对战
- 追求最优输出

**智能逻辑**：

```csharp
public Skill SelectBestSkill(BattleContext context)
{
    // 1. 血量判断
    if (context.Self.HP < context.Self.MaxHP * 0.3f)
    {
        // 低血量优先治疗
        var healSkill = GetAvailableSkill(SkillType.Heal);
        if (healSkill != null) return healSkill;
    }

    // 2. 敌方血量判断（斩杀）
    if (context.Target.HP < context.Target.MaxHP * 0.2f)
    {
        // 低血量使用斩杀技能
        var executeSkill = GetAvailableSkill(SkillType.Execute);
        if (executeSkill != null) return executeSkill;
    }

    // 3. Buff检查
    if (!HasBuff(BuffType.AttackUp))
    {
        // 没有攻击Buff时优先加Buff
        var buffSkill = GetAvailableSkill(SkillType.AttackBuff);
        if (buffSkill != null) return buffSkill;
    }

    // 4. Debuff检查
    if (!TargetHasDebuff(DebuffType.DefenseDown))
    {
        // 敌方没有破甲时优先破甲
        var debuffSkill = GetAvailableSkill(SkillType.DefenseDebuff);
        if (debuffSkill != null) return debuffSkill;
    }

    // 5. 冷却和蓝量优化
    // 优先使用高伤害且即将进入冷却的技能
    // 避免蓝量溢出或枯竭

    // 6. 默认使用最高伤害技能
    return GetHighestDamageSkill();
}
```

### 5.5 策略切换

```
战斗中可实时切换策略：
- 默认使用智能策略
- 长按技能按钮切换策略
- 可在设置中预设默认策略

不同场景推荐策略：
- 日常刷怪：顺序释放
- BOSS战：智能释放
- PVP：智能释放
- 测试：随机释放
```

## 六、多段伤害机制

### 6.1 多段技能设计

多段伤害技能在一次施法中造成多次伤害，每次可独立计算：

| 技能ID | 名称 | 段数 | 每段效果 |
|--------|------|------|----------|
| 16 | 连环斩 | 3 | 0.6x / 0.6x / 0.6x |
| 51 | 连环斩(多段) | 2 | 85%+500 / 135%+1000 |
| 52 | 元素爆发 | 3 | 物理60%+300 / 法术80%+400 / 真实100%+500 |
| 56 | 连环毒刃 | 2 | 70%+200+毒 / 90%+300+毒 |
| 57 | 连环火球 | 4 | 50%+100×4+灼烧 |
| 58 | 狂风暴雨 | 5 | 40%+50×5 |
| 59 | 旋风斩 | 3 | 50%+100×3 |
| 60 | 神圣审判 | 2 | 100%+200 / 150%+300+多Debuff |

### 6.2 多段伤害计算

```
总伤害 = Σ(每段伤害)

每段伤害独立计算：
- 独立计算命中率
- 独立计算暴击
- 独立计算目标防御
- 独立触发特效

示例：连环斩（3段，每段0.6倍）
玩家攻击：200
目标防御：100

段1：200×0.6 = 120 → 120²/(120+100) = 65（命中，未暴击）
段2：200×0.6 = 120 → 120²/(120+100) = 130（命中，暴击）
段3：200×0.6 = 120 → Miss（未命中）

总伤害 = 65 + 130 = 195
对比普通攻击1.5倍：200×1.5 = 300 → 300²/(300+100) = 225

多段优势：多次触发特效、更稳定的伤害输出
多段劣势：每段独立计算防御、受闪避影响更大
```

### 6.3 多段技能升级

多段技能升级可提升：
- 每段伤害倍率
- 段数（某些技能）
- 附加效果触发概率

```
示例：狂风暴雨升级

1级：5段，每段40%+50
5级：5段，每段48%+60，+10%暴击率
10级：6段，每段55%+70，+20%暴击率，最后一段必暴击
```

### 7.2 Buff影响技能

```
攻击提升Buff：
- 增加所有伤害技能的伤害
- 计算公式：最终伤害 = 基础伤害 × (1 + Buff加成)

防御降低Debuff：
- 增加对目标的伤害
- 计算公式：实际防御 = 基础防御 × (1 - Debuff比例)

暴击提升Buff：
- 增加暴击概率
- 可叠加至100%暴击

冷却缩减Buff：
- 减少技能冷却时间
- 每回合额外减少冷却点数
```

```csharp
// 技能升级
public bool UpgradeSkill(int skillId)
{
    var skill = GetSkillInstance(skillId);
    var template = GetSkillTemplate(skillId);

    if (skill.CurrentLevel >= template.MaxLevel)
        return false;

    // 检查熟练度
    int requiredExp = GetRequiredExp(skill.CurrentLevel);
    if (skill.CurrentExp < requiredExp)
        return false;

    // 检查金币
    int requiredGold = GetUpgradeCost(skill.CurrentLevel, template);
    if (!ConsumeGold(requiredGold))
        return false;

    // 检查技能书
    if (template.RequireSkillBook)
    {
        int requiredBooks = GetRequiredBooks(skill.CurrentLevel, template);
        if (!ConsumeItem(ItemType.SkillBook, skillId, requiredBooks))
            return false;
    }

    // 执行升级
    skill.CurrentLevel++;
    skill.CurrentExp = 0;

    return true;
}

// 智能选择技能
public Skill SelectSmartSkill(List<Skill> availableSkills, BattleContext context)
{
    Skill bestSkill = null;
    float bestScore = 0;

    foreach (var skill in availableSkills)
    {
        float score = EvaluateSkillScore(skill, context);
        if (score > bestScore)
        {
            bestScore = score;
            bestSkill = skill;
        }
    }

    return bestSkill;
}

private float EvaluateSkillScore(Skill skill, BattleContext context)
{
    float score = skill.DamageMultiplier * 100;  // 基础伤害分数

    // 根据场景调整分数
    if (skill.DamageType == DamageType.Heal && context.Self.HPPercent < 0.3f)
        score += 500;  // 低血量时治疗优先

    if (skill.HasBuff(BuffType.AttackUp) && !context.Self.HasBuff(BuffType.AttackUp))
        score += 300;  // 没有攻击Buff时加Buff优先

    if (skill.HasDebuff(DebuffType.DefenseDown) && !context.Target.HasDebuff(DebuffType.DefenseDown))
        score += 250;  // 没有破甲时破甲优先

    return score;
}
```

## 九、平衡性验证

### 9.1 技能DPS对比

```
假设：玩家攻击200，目标防御100，蓝量充足

单段技能：
- 重击（1.5倍）：伤害 = 200×1.5 = 300 → 实际伤害 = 300²/(300+100) = 225
- 火球术（1.8倍）：伤害 = 200×1.8 = 360 → 实际伤害 = 360²/(360+100) = 281

多段技能（3段，每段0.6倍）：
- 理论总倍率：1.8倍
- 实际伤害（假设全中）：3 × (120²/(120+100)) = 3 × 65 = 195

结论：多段技能总伤害略低于单段，但更稳定，且可多次触发特效
```

### 9.2 技能升级收益

```
10级技能 vs 1级技能：
- 伤害倍率：+50%
- Buff效果：+30%
- 消耗增加：+50%蓝耗

投入产出比：
- 升级消耗：约26000熟练度 + 约5500金币 + 技能书
- 收益：50%伤害提升

结论：技能升级收益可观，但需要持续投入，形成长期追求
```

### 9.3 技能搭配平衡

```
技能栏位限制：6个主动技能

流派差异：
- 物理输出流：3输出 + 1Buff + 1控制 + 1治疗
- 法术爆发流：3法术 + 2Buff + 1控制
- 均衡发展流：2输出 + 2Buff + 1控制 + 1治疗

验证：不同流派有不同优势场景，没有绝对最优解
```
