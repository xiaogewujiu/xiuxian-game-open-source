灵田系统设计方案

## 背景与目标

灵田系统是游戏的资源产出系统，玩家可以在灵田中种植各类草药，用于炼丹或直接食用获得经验。本方案设计固定6块灵田、土地升级系统、种植收获机制，构建稳定的资源产出体系。

## 一、灵田系统概览

### 1.1 核心设计原则

| 原则 | 说明 |
|------|------|
| 固定数量 | 6块灵田，不扩展，简化管理 |
| 土地升级 | 升级土地提升产量，形成成长感 |
| 时间收益 | 种植需要等待，体现时间价值 |
| 资源循环 | 产出→炼丹→提升→更高效产出 |

### 1.2 数据结构

```csharp
public class SpiritFieldSystem
{
    public string PlayerId { get; set; }
    public List<FieldPlot> Plots { get; set; }    // 6块灵田
    public int TotalHarvestCount { get; set; }    // 累计收获次数
}

public class FieldPlot
{
    public int PlotId { get; set; }               // 灵田编号（1-6）
    public int Level { get; set; }                // 土地等级
    public FieldStatus Status { get; set; }       // 土地状态
    public int CurrentCropId { get; set; }        // 当前作物ID
    public DateTime PlantTime { get; set; }       // 种植时间
    public DateTime HarvestTime { get; set; }     // 预计收获时间
    public int FertilizerBonus { get; set; }      // 肥料加成（%）
}

public enum FieldStatus
{
    Empty = 0,        // 空闲
    Growing = 1,      // 生长中
    Mature = 2,       // 可收获
    Withered = 3      // 枯萎（可选）
}

public class CropTemplate
{
    public int CropId { get; set; }               // 作物ID
    public string Name { get; set; }              // 作物名称
    public int GrowthTime { get; set; }           // 生长时间（分钟）
    public int BaseYield { get; set; }            // 基础产量
    public List<CropProduct> Products { get; set; } // 产出物品
    public int UnlockLevel { get; set; }          // 解锁等级
}
```

## 九、实现方案

```csharp
// 种植作物
public PlantResult PlantCrop(string playerId, int plotId, int cropId)
{
    var plot = GetPlot(playerId, plotId);
    var crop = GetCropTemplate(cropId);

    // 检查土地状态
    if (plot.Status != FieldStatus.Empty)
        return PlantResult.PlotNotEmpty;

    // 检查种子
    if (!HasSeed(playerId, cropId))
        return PlantResult.NoSeed;

    // 计算生长时间
    int growthTime = CalculateGrowthTime(crop.GrowthTime, plot.Level);

    // 种植
    plot.Status = FieldStatus.Growing;
    plot.CurrentCropId = cropId;
    plot.PlantTime = DateTime.Now;
    plot.HarvestTime = DateTime.Now.AddMinutes(growthTime);

    // 消耗种子
    ConsumeSeed(playerId, cropId);

    SavePlot(plot);

    return PlantResult.Success;
}

// 收获作物
public HarvestResult HarvestCrop(string playerId, int plotId)
{
    var plot = GetPlot(playerId, plotId);
    var crop = GetCropTemplate(plot.CurrentCropId);

    // 检查是否成熟
    if (DateTime.Now < plot.HarvestTime)
        return HarvestResult.NotMature;

    // 计算产量
    int yield = CalculateYield(crop.BaseYield, plot);

    // 发放产出
    GiveItem(playerId, crop.ProductId, yield);

    // 概率获得种子
    if (Random.Range(0f, 1f) < 0.2f)
    {
        GiveItem(playerId, crop.SeedId, 1);
    }

    // 重置土地
    plot.Status = FieldStatus.Empty;
    plot.CurrentCropId = 0;
    plot.FertilizerBonus = 0;

    // 更新统计
    var system = GetSystem(playerId);
    system.TotalHarvestCount++;

    SavePlot(plot);

    return new HarvestResult { Yield = yield };
}

// 计算生长时间
private int CalculateGrowthTime(int baseTime, int plotLevel)
{
    float reduction = 0f;
    if (plotLevel >= 4) reduction = 0.1f;
    if (plotLevel >= 6) reduction = 0.15f;
    if (plotLevel >= 8) reduction = 0.2f;
    if (plotLevel >= 10) reduction = 0.25f;

    return (int)(baseTime * (1 - reduction));
}

// 计算产量
private int CalculateYield(int baseYield, FieldPlot plot)
{
    float multiplier = 1f;

    // 土地等级加成
    multiplier += (plot.Level - 1) * 0.2f;

    // 肥料加成
    multiplier += plot.FertilizerBonus / 100f;

    // 双倍产出概率
    doubleChance = 0f;
    if (plot.Level >= 6) doubleChance = 0.05f;
    if (plot.Level >= 8) doubleChance = 0.1f;
    if (plot.Level >= 10) doubleChance = 0.15f;

    if (Random.Range(0f, 1f) < doubleChance)
        multiplier *= 2;

    // 随机波动
    multiplier *= Random.Range(0.8f, 1.2f);

    return (int)(baseYield * multiplier);
}
```

## 十、平衡性验证

### 10.1 产出效率验证

```
假设玩家6块满级土地，全部种植人参：
- 生长时间：1小时36分钟
- 单次产量：约10个/块
- 6块总产量：约60个/轮
- 每日轮次：约15轮
- 日产量：约900个人参

对比炼丹需求：
- 一颗高级丹药约需5个人参
- 日产量可炼制约180颗丹药
- 满足日常炼丹需求
```

### 10.2 经济平衡

```
种植成本：
- 人参种子：1000金币
- 6块地种子：6000金币
- 15轮种子：90000金币/天

产出价值：
- 900个人参
- 商店价格：约500金币/个
- 总价值：450000金币

净收益：约360000金币/天

结论：灵田是重要收入来源，但需要时间投入和前期升级投资
```
