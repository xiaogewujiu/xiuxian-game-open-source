地图系统设计方案

## 背景与目标

地图系统是游戏世界探索的核心载体，玩家通过在不同地图中战斗获取经验、装备和材料。本方案基于现有地图数据，设计完整的地图解锁机制、怪物配置、掉落系统和探索玩法。

## 一、地图系统概览

### 1.1 核心设计原则

| 原则 | 说明 |
|------|------|
| 等级递进 | 地图难度随等级递增，形成清晰的成长路线 |
| 属性主题 | 每张地图对应五行属性之一，掉落对应属性材料 |
| 野怪分布 | 每张地图3种野怪，分别对应普通/精英/BOSS难度 |
| 奖励递增 | 高级地图提供更高品质的装备和更多材料 |

### 1.2 地图数据结构

```csharp
public class MapData
{
    public string MapGId { get; set; }        // 地图唯一ID
    public string Name { get; set; }          // 地图名称
    public int Level { get; set; }            // 推荐等级
    public string Description { get; set; }   // 地图描述
    public string NextMapId { get; set; }     // 下一张地图ID
    public bool Carrying { get; set; }        // 是否可携带宠物
    public (int, int) MonsterCount { get; set; }  // 怪物数量范围
    public List<string> MonsterTemplateIds { get; set; }  // 怪物模板ID列表
    public Element ElementType { get; set; }  // 地图五行属性
}
```

### 2.2 地图解锁机制

**线性解锁**
```
新手村(1级) → 迷雾森林(5级) → 荒芜山脉(10级) → 幽暗沼泽(15级) → 烈焰谷(20级)
     ↓
寒冰洞(25级) → 雷鸣峰(30级) → 风啸原(35级) → 金沙遗迹(40级) → 木灵秘境(45级)
     ↓
五行禁地(50级)
```

**解锁条件**
| 条件类型 | 说明 | 应用地图 |
|----------|------|----------|
| 等级限制 | 达到指定等级自动解锁 | 所有地图 |
| 前置通关 | 需通关上一张地图 | 迷雾森林及之后 |
| 任务解锁 | 完成特定主线任务 | 特殊地图（可选） |

```
基础攻击 = 8 + (等级-1) × 2
```

```
消耗：对应体力值
奖励：该地图平均战斗收益 × 0.8（效率惩罚）

限制：每日最多快速探索20次
```

## 六、战斗机制

### 6.1 怪物数量

```
每场战斗怪物数量 = Random(最小数量, 最大数量)

普通探索：2-4只
精英挑战：1只精英 + 0-2只普通
BOSS讨伐：1只BOSS + 1-2只精英
```

### 6.2 战斗难度调整

**根据玩家等级调整**：
```
等级差 = 玩家等级 - 地图等级

等级差 ≥ 10：怪物属性降低50%，收益降低80%
等级差 5-9：怪物属性降低30%，收益降低50%
等级差 0-4：正常难度和收益
等级差 -5到-1：怪物属性提升20%，收益提升20%
等级差 ≤ -6：怪物属性提升50%，收益提升50%
```

### 7.2 核心算法

```csharp
// 获取地图推荐装备等级
public int GetRecommendedEquipmentLevel(string mapId)
{
    var map = GetMapById(mapId);
    return map.Level;  // 装备等级与地图等级相同
}

// 计算掉落装备等级
public int GetDropEquipmentLevel(string mapId)
{
    var map = GetMapById(mapId);
    var random = new Random();

    // 掉落等级 = 地图等级 ± 5级
    return Math.Max(1, map.Level + random.Next(-5, 6));
}

// 生成怪物队伍
public List<Monster> SpawnMonsters(string mapId, BattleType type)
{
    var map = GetMapById(mapId);
    var monsters = new List<Monster>();

    switch (type)
    {
        case BattleType.Normal:
            int count = Random.Range(map.MonsterCount.Item1, map.MonsterCount.Item2 + 1);
            for (int i = 0; i < count; i++)
            {
                var templateId = GetRandomMonsterTemplateId(map);
                monsters.Add(CreateMonster(templateId));
            }
            break;

        case BattleType.Elite:
            monsters.Add(CreateMonster(map.EliteMonsterId));
            break;

        case BattleType.Boss:
            monsters.Add(CreateMonster(map.BossMonsterId));
            break;
    }

    return monsters;
}
```

## 八、平衡性验证

### 8.1 升级所需战斗场次估算

```
假设：
- 玩家主要在当前等级地图战斗
- 平均每次战斗获得中等经验值
- 升级经验曲线：LevelConfig

1-10级：每场战斗约20经验，升级需100-500经验 ≈ 5-25场
11-25级：每场战斗约150经验，升级需2000-10000经验 ≈ 15-70场
26-40级：每场战斗约400经验，升级需15000-50000经验 ≈ 40-125场
41-50级：每场战斗约800经验，升级需60000-150000经验 ≈ 75-190场

总计1-50级约需战斗：2000-3000场（约7-10天活跃游戏时间）
```

```
假设：
- 每件装备平均战斗10场获得1件
- 全身7件装备

初期（1-20级）：约70场战斗可凑齐一套同级装备
中期（21-40级）：约140场战斗可凑齐一套同级装备
后期（41-50级）：约280场战斗可凑齐一套同级装备（考虑品质需求）
```

### 8.3 材料产出验证

```
聚灵阵升级消耗（假设）：
- 1→2级：50个对应属性材料
- 在对应地图战斗，每场平均获得1.5个材料
```
