商店系统设计方案

## 背景与目标

商店系统是游戏经济系统的核心流通渠道，为玩家提供道具、装备、材料的购买途径。本方案设计支持多货币（灵石、金币、道具）的普通商店系统，包含商品分类、刷新机制、限购规则等，构建可持续的游戏内经济循环。

## 一、商店系统概览

### 1.1 核心设计原则

| 原则 | 说明 |
|------|------|
| 多货币支持 | 支持灵石、金币、道具物品等多种支付方式 |
| 商品多样 | 涵盖装备、道具、材料、丹药等多种类型 |
| 动态刷新 | 部分商品定期刷新，增加玩家回访动力 |
| 限购控制 | 防止囤积和通货膨胀，保持经济平衡 |

### 5.1 限购类型

| 类型 | 说明 | 重置时间 |
|------|------|----------|
| 每日限购 | 每天可购买的数量 | 每日0点 |
| 每周限购 | 每周可购买的数量 | 周一0点 |
| 每月限购 | 每月可购买的数量 | 每月1日0点 |

### 5.2 限购设计原则

```
消耗品：高限购或不限购（日常需求大）
强化材料：中等限购（控制强化进度）
稀有道具：低限购（保持稀有度）
装备：低限购（防止装备贬值）
```

### 9.2 核心算法

```csharp
// 购买商品
public PurchaseResult PurchaseItem(int shopId, int itemIndex, int count)
{
    var shop = GetShop(shopId);
    var item = shop.Items[itemIndex];

    // 检查等级要求
    if (player.Level < item.LevelRequired)
        return PurchaseResult.LevelNotEnough;

    // 检查限购
    var purchaseRecord = GetPurchaseRecord(player.Id, item.ItemId);
    if (item.DailyLimit > 0 && purchaseRecord.DailyCount + count > item.DailyLimit)
        return PurchaseResult.DailyLimitReached;
    if (item.WeeklyLimit > 0 && purchaseRecord.WeeklyCount + count > item.WeeklyLimit)
        return PurchaseResult.WeeklyLimitReached;

    // 计算总价
    int totalPrice = (int)(item.Price * count * (1 - item.Discount));

    // 检查货币
    if (!HasEnoughCurrency(player, item.Currency, totalPrice))
        return PurchaseResult.InsufficientCurrency;

    // 检查背包空间
    if (!HasEnoughInventorySpace(player, item.ItemId, count))
        return PurchaseResult.InventoryFull;

    // 扣除货币
    ConsumeCurrency(player, item.Currency, totalPrice);

    // 发放道具
    GiveItem(player, item.ItemId, count);

    // 更新限购记录
    UpdatePurchaseRecord(player.Id, item.ItemId, count);

    return PurchaseResult.Success;
}

// 刷新商店
public void RefreshShop(int shopId)
{
    var shop = GetShop(shopId);

    // 生成新商品
    var newItems = GenerateShopItems(shop.Type, player.Level);
    shop.Items = newItems;
    shop.LastRefreshTime = DateTime.Now;

    SaveShop(shop);
}
```

## 十、平衡性验证

### 10.1 商店与掉落平衡

```
商店价格 vs 掉落价值：

生命药水：
- 商店价格：50金币
- 战斗掉落：约20%概率
- 等效价值：每场战斗平均价值约10金币

强化石：
- 商店价格：500金币
- 副本掉落：约50%概率
- 等效价值：每次副本约2-3个

结论：商店价格略高于掉落价值，防止商店成为唯一来源，同时提供便捷的补充途径
```

### 10.2 灵石消耗控制

```
假设玩家每日灵石支出：
- 保护石：5×100 = 500灵石
- 高级强化石：5×50 = 250灵石
- 珍品商店：平均300灵石
- 手动刷新：平均100灵石

每日总支出：约1150灵石

对比灵石获取：
- 签到：约15灵石/天
- 活动：约50灵石/天
- 成就：平均约30灵石/天
- 充值：视付费情况而定

结论：免费玩家需要谨慎选择消费，付费玩家有充足消费能力，平衡合理
```
