装备系统设计方案

## 背景与目标

装备系统是玩家战力成长的核心系统。本方案基于现有装备数据，设计完整的装备品质体系、槽位配置、属性成长、强化洗练机制，构建装备从获取到毕业的成长路线。

## 一、装备系统概览

### 1.1 核心设计原则

| 原则 | 说明 |
|------|------|
| 品质分级 | 5种品质区分装备稀有度，影响基础属性和成长上限 |
| 槽位专精 | 7个槽位各有侧重，武器类型决定流派方向 |
| 数值成长 | 装备等级与玩家等级挂钩，形成清晰成长曲线 |
| 深度养成 | 强化和洗练提供长期追求目标 |

### 1.2 装备数据结构

```csharp
// 装备模板（配置数据）
public class EquipmentTemplate
{
    public int EquipmentId { get; set; }      // 装备ID
    public string Name { get; set; }          // 装备名称
    public int Level { get; set; }            // 装备等级
    public EquipmentQuality Quality { get; set; }  // 装备品质
    public EquipmentSlot Slot { get; set; }   // 装备槽位
    public string Description { get; set; }   // 装备描述
    public float QualityMultiplier { get; set; }  // 品质倍率

    // 属性范围（Type1-Type15）
    public Dictionary<AttributeType, (float Min, float Max)> AttributeRanges { get; set; }
}

// 装备实例（玩家拥有的装备）
public class EquipmentInstance
{
    public EquipmentTemplate Template { get; set; }  // 模板引用
    public string InstanceId { get; set; }      // 实例唯一ID
    public int EnhanceLevel { get; set; }       // 强化等级
    public List<AttributeProperty> RerolledAttrs { get; set; }  // 洗练属性
    public int RerollCount { get; set; }        // 洗练次数
    public List<AttributeProperty> Attributes { get; set; }  // 原始随机属性
}
```

## 六、装备生成规则

### 6.1 随机属性生成

```csharp
// 属性生成算法
public List<AttributeProperty> GenerateAttributes(EquipmentTemplate template)
{
    var attributes = new List<AttributeProperty>();
    var random = new Random();

    foreach (var attrRange in template.AttributeRanges)
    {
        // 在Min-Max范围内随机取值
        float value = random.NextFloat(attrRange.Value.Min, attrRange.Value.Max);

        // 应用品质倍率
        value *= template.QualityMultiplier;

        // 取整（基础属性）或保留2位小数（百分比属性）
        if (IsPercentageAttribute(attrRange.Key))
            value = (float)Math.Round(value, 2);
        else
            value = (int)value;

        attributes.Add(new AttributeProperty
        {
            Type = attrRange.Key,
            Value = value
        });
    }

    return attributes;
}
```

## 九、装备评分系统

### 9.1 评分计算公式

```
装备评分 = 基础属性评分 + 强化评分 + 洗练评分

基础属性评分 = Σ(属性值 × 属性权重)
强化评分 = 强化等级 × 100
洗练评分 = Σ(洗练属性值 × 属性权重 × 品质系数)

属性权重：
- 血量：0.5
- 蓝量：0.3
- 物攻/法攻：2.0
- 物防/法防：1.0
- 速度：1.5
- 百分比属性：1000（转换为整数后）
```

### 9.2 战力榜计算

```
总战力 = Σ(所有装备评分) + 属性点加成评分 + 其他系统评分

装备对战力贡献占比建议：60-70%
```

### 11.2 核心算法

```csharp
// 计算装备总属性
public List<AttributeProperty> GetTotalAttributes(EquipmentInstance equipment)
{
    var totalAttrs = new Dictionary<AttributeType, float>();

    // 1. 复制基础属性
    foreach (var attr in equipment.Attributes)
    {
        totalAttrs[attr.Type] = attr.Value;
    }

    // 2. 应用强化加成
    float enhanceBonus = 1.0f + equipment.EnhanceLevel * 0.05f;
    foreach (var attr in totalAttrs.Keys.ToList())
    {
        totalAttrs[attr] *= enhanceBonus;
    }

    // 3. 叠加洗练属性
    foreach (var attr in equipment.RerolledAttrs)
    {
        if (totalAttrs.ContainsKey(attr.Type))
            totalAttrs[attr.Type] += attr.Value;
        else
            totalAttrs[attr.Type] = attr.Value;
    }

    return totalAttrs.Select(kv => new AttributeProperty
    {
        Type = kv.Key,
        Value = kv.Value
    }).ToList();
}

// 强化装备
public EnhanceResult Enhance(EquipmentInstance equipment, bool useProtectStone)
{
    int currentLevel = equipment.EnhanceLevel;
    int maxLevel = GetMaxEnhanceLevel(equipment.Template.Quality);

    if (currentLevel >= maxLevel)
        return EnhanceResult.MaxLevelReached;

    float successRate = GetSuccessRate(currentLevel, equipment.Template.Quality);
    bool success = Random.Range(0f, 1f) < successRate;

    if (success)
    {
        equipment.EnhanceLevel++;
        return EnhanceResult.Success;
    }
    else
    {
        // 处理失败惩罚
        int degradeLevel = CalculateDegrade(currentLevel, useProtectStone);
        equipment.EnhanceLevel = Mathf.Max(0, currentLevel - degradeLevel);
        return useProtectStone ? EnhanceResult.FailedButProtected : EnhanceResult.FailedAndDegraded;
    }
}
```
