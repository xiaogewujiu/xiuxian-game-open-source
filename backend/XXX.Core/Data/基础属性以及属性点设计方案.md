 背景与目标

 根据当前装备数值和野怪数值，设计合理的1级人物基础数值，并建立属性点分配系统：
 - 升级不自动增长属性
 - 改为获得属性点
 - 玩家自由分配属性点

 四、战斗平衡验证

 场景1：1级裸装 vs 史莱姆

 - 人物：血量100，攻击12，防御8
 - 史莱姆：血量100，攻击10，防御8

 人物攻击史莱姆：
 伤害 = 12² / (12 + 8) = 144 / 20 = 7.2
 击杀需要：100 / 7.2 ≈ 14次攻击

 史莱姆攻击人物：
 伤害 = 10² / (10 + 8) = 100 / 18 = 5.56
 击杀需要：100 / 5.56 ≈ 18次攻击

 结论：人物略占优势，合理。

 场景2：1级全身装备 vs 灰狼

 - 人物基础：血量100，攻击12，防御8
 - 装备加成：血量+60，攻击+5，防御+12
 - 人物总计：血量160，攻击17，防御20
 - 灰狼：血量110，攻击12，防御8

 人物攻击灰狼：
 伤害 = 17² / (17 + 8) = 289 / 25 = 11.56
 击杀需要：110 / 11.56 ≈ 10次攻击

 灰狼攻击人物：
 伤害 = 12² / (12 + 20) = 144 / 32 = 4.5
 击杀需要：160 / 4.5 ≈ 36次攻击

 结论：装备优势明显，可轻松击败同级怪物，合理。

 场景3：50级满属性点 vs 50级怪物

 假设50级玩家将所有属性点投入攻击：
 - 基础物攻：12
 - 属性点加成：222点 × 2 = 444攻击
 - 装备加成（50级武器）：约250攻击
 - 总计：约706攻击

 50级怪物防御：约150
 伤害 = 706² / (706 + 150) = 498436 / 856 ≈ 582

 50级怪物血量：约3000
 击杀需要：3000 / 582 ≈ 6次攻击

 结论：符合高级角色快速击败怪物的预期。

 五、实现方案

 需要修改的文件

 1. Entity/Entities.cs
   - 在 UserEntity 中添加：AttributePoints 属性点字段
   - 添加：TotalAttributePoints 总获得属性点字段（用于显示）
 2. Player/LevelConfig.cs
   - 移除或注释掉自动属性增长逻辑
   - 添加属性点获取配置表
 3. Player/PlayerManager.cs
   - 修改升级处理逻辑，不再自动增加属性
   - 改为发放属性点
 4. 新建 Player/AttributePointSystem.cs
   - 属性点分配逻辑
   - 属性点兑换计算
   - 重置属性点功能（可选）
 5. Data/GameConfig.cs（或新建配置文件）
   - 属性点兑换比例配置

 // 属性点兑换配置
 public static class AttributePointConfig
 {
     // 基础属性兑换
     public static readonly Dictionary<AttributeType, float> BaseAttributeRatio = new()
     {
         { AttributeType.Type1, 15f },   // 血量 +15/点
         { AttributeType.Type2, 8f },    // 蓝量 +8/点
         { AttributeType.Type3, 2f },    // 物攻 +2/点
         { AttributeType.Type4, 2f },    // 法攻 +2/点
         { AttributeType.Type5, 1.5f },  // 物防 +1.5/点
         { AttributeType.Type6, 1.5f },  // 法防 +1.5/点
         { AttributeType.Type7, 1.5f },  // 速度 +1.5/点
     };

     // 升级获得属性点
     public static int GetAttributePointsForLevel(int level)
     {
         if (level <= 10) return 3;
         if (level <= 25) return 4;
         if (level <= 40) return 5;
         return 6;
     }
 }
