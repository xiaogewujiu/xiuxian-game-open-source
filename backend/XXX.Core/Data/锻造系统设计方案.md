锻造系统设计方案

## 背景与目标

锻造系统是玩家自主打造装备的核心玩法，通过提升锻造台等级和锻造师等级，玩家可以锻造出更高品质、更强属性的装备。锻造等级受五行聚灵阵等级限制，形成养成依赖关系。

## 一、锻造系统概览

### 1.1 核心设计原则

| 原则 | 说明 |
|------|------|
| 等级制约 | 锻造台等级 ≤ 聚灵阵等级 + 5 |
| 双轨成长 | 锻造台等级 + 锻造师等级共同影响锻造效果 |
| 成功风险 | 锻造有成功率，高级装备风险更高 |
| 品质差异 | 锻造产出有不同品质，受等级影响 |

### 1.2 数据结构

```csharp
public class ForgeSystem
{
    public string PlayerId { get; set; }
    public int ForgeLevel { get; set; }           // 锻造台等级
    public int BlacksmithLevel { get; set; }      // 锻造师等级
    public int BlacksmithExp { get; set; }        // 锻造师经验
    public int ForgeCount { get; set; }           // 累计锻造次数
}

public class ForgeRecipe
{
    public int RecipeId { get; set; }             // 配方ID
    public EquipmentSlot Slot { get; set; }       // 装备槽位
    public int MinLevel { get; set; }             // 最低锻造等级
    public List<ForgeMaterial> Materials { get; set; } // 所需材料
    public int BaseSuccessRate { get; set; }      // 基础成功率
}

public class ForgeResult
{
    public bool Success { get; set; }             // 是否成功
    public EquipmentInstance Equipment { get; set; } // 产出的装备
    public EquipmentQuality Quality { get; set; } // 产出品质
    public int ExpGained { get; set; }            // 获得的经验
}
```

## 二、锻造台等级系统

### 2.1 等级上限

```
锻造台等级上限 = Min(聚灵阵等级 + 5, 50)

示例：
聚灵阵25级 → 锻造台最高30级
聚灵阵45级 → 锻造台最高50级
聚灵阵50级 → 锻造台最高50级（封顶）
```

### 2.2 升级消耗

| 锻造台等级 | 升级消耗金币 | 升级消耗材料 | 解锁功能 |
|------------|--------------|--------------|----------|
| 1→10级 | 1000×等级 | 铁矿×10 | 打造1-20级装备 |
| 11→20级 | 3000×等级 | 精铁×10 | 打造21-30级装备 |
| 21→30级 | 8000×等级 | 玄铁×10 | 打造31-40级装备 |
| 31→40级 | 20000×等级 | 陨铁×5 | 打造41-45级装备 |
| 41→50级 | 50000×等级 | 神铁×3 | 打造46-50级装备 |

### 2.3 锻造台等级影响

| 等级 | 成功率加成 | 品质加成 | 可打造最高装备等级 |
|------|------------|----------|-------------------|
| 1级 | 0% | 普通为主 | 10级 |
| 10级 | +5% | 优秀概率提升 | 20级 |
| 20级 | +10% | 稀有概率提升 | 30级 |
| 30级 | +15% | 史诗概率提升 | 40级 |
| 40级 | +20% | 传说概率提升 | 45级 |
| 50级 | +25% | 传说概率大幅提升 | 50级 |

## 三、锻造师等级系统

### 3.1 经验获取

| 锻造结果 | 获得经验 | 说明 |
|----------|----------|------|
| 普通品质成功 | 10经验 | 基础经验 |
| 优秀品质成功 | 20经验 | 1.5倍经验 |
| 稀有品质成功 | 40经验 | 2倍经验 |
| 史诗品质成功 | 80经验 | 3倍经验 |
| 传说品质成功 | 200经验 | 5倍经验 |
| 锻造失败 | 5经验 | 安慰奖 |

### 3.2 等级上限

```
锻造师等级上限 = 锻造台等级

设计理念：
- 锻造师等级不能超过锻造台等级
- 避免高等级锻造师使用低级锻造台的不匹配情况
```

### 3.3 等级效果

| 锻造师等级 | 成功率加成 | 品质加成 | 特殊效果 |
|------------|------------|----------|----------|
| 1-10级 | +0% | 无 | 基础锻造 |
| 11-20级 | +3% | 品质+1% | 可修复失败 |
| 21-30级 | +6% | 品质+3% | 保底优秀 |
| 31-40级 | +10% | 品质+5% | 保底稀有 |
| 41-50级 | +15% | 品质+8% | 保底史诗 |

## 五、锻造成功率公式

### 5.1 基础成功率

```
基础成功率 = 装备等级基础率 + 锻造台加成 + 锻造师加成 + 五行加成

装备等级基础率：
1-20级装备：80%
21-30级装备：70%
31-40级装备：60%
41-45级装备：50%
46-50级装备：40%

锻造台加成：锻造台等级 × 0.5%
锻造师加成：锻造师等级 × 0.3%
五行加成（金属性）：金属性等级 × 0.2%
```

### 5.2 成功率计算示例

```
场景：锻造40级武器
- 锻造台等级：35级
- 锻造师等级：30级
- 金属性等级：28级

计算：
基础成功率：60%（40级装备）
锻造台加成：35 × 0.5% = 17.5%
锻造师加成：30 × 0.3% = 9%
五行加成：28 × 0.2% = 5.6%

总成功率：60 + 17.5 + 9 + 5.6 = 92.1%
最高不超过95%
```

### 5.3 必成机制

```
当锻造师等级 ≥ 装备等级要求 + 10级时：
- 成功率固定为100%
- 但品质不会高于史诗

示例：
锻造30级武器，锻造师40级
成功率：100%
最高品质：史诗

设计理念：
- 避免过度失败挫败感
- 但仍有追求更高品质的动力
```

| 锻造台等级 | 普通 | 优秀 | 稀有 | 史诗 | 传说 |
|------------|------|------|------|------|------|
| 1-10级 | 60% | 30% | 9% | 1% | 0% |
| 11-20级 | 50% | 35% | 12% | 3% | 0% |
| 21-30级 | 40% | 35% | 18% | 6% | 1% |
| 31-40级 | 30% | 35% | 22% | 10% | 3% |
| 41-50级 | 20% | 30% | 28% | 15% | 7% |

### 6.2 锻造师等级品质加成

```
品质加成：锻造师等级 × 0.2%

效果：
- 将低品质概率转化为高品质概率
- 优先转化为相邻高品质

示例：锻造台30级，锻造师30级
基础概率：普通40%，优秀35%，稀有18%，史诗6%，传说1%
品质加成：30 × 0.2% = 6%

调整后：
普通：40 - 6 = 34%
优秀：35 + 3 = 38%
稀有：18 + 2 = 20%
史诗：6 + 1 = 7%
传说：1%
```

## 八、特殊锻造功能

### 8.1 批量锻造

```
解锁：锻造师等级20级

功能：
- 同时锻造多件相同装备
- 自动使用材料直到材料不足或达到设定数量
- 批量显示结果

限制：
- 一次最多10件
- 品质随机独立计算
```

### 8.2 指定属性锻造

```
解锁：锻造师等级30级
消耗：额外材料×50%

功能：
- 锻造时指定1条想要的属性类型
- 产出装备必定包含该属性
- 属性数值随机

限制：
- 每天限3次
- 不能指定所有属性
```

### 8.3 装备重铸

```
解锁：锻造师等级40级
消耗：原装备 + 材料

功能：
- 将已有装备重新锻造
- 保留强化等级
- 重新随机属性和品质

限制：
- 洗练属性清除
- 每次重铸成功率-10%
```

## 十、实现方案

### 10.1 核心算法

```csharp
// 计算锻造成功率
public float CalculateSuccessRate(ForgeRecipe recipe, ForgeSystem system)
{
    float baseRate = GetBaseSuccessRate(recipe.MinLevel);
    float forgeBonus = system.ForgeLevel * 0.005f;
    float smithBonus = system.BlacksmithLevel * 0.003f;
    float elementBonus = GetMetalElementLevel(system.PlayerId) * 0.002f;

    float totalRate = baseRate + forgeBonus + smithBonus + elementBonus;
    return Math.Min(totalRate, 0.95f);  // 最高95%
}

// 执行锻造
public ForgeResult ExecuteForge(ForgeRecipe recipe, ForgeSystem system, bool useGuarantee)
{
    var result = new ForgeResult();
    float successRate = CalculateSuccessRate(recipe, system);

    // 判定成功
    bool isSuccess = useGuarantee || Random.Range(0f, 1f) < successRate;

    if (isSuccess)
    {
        result.Success = true;
        result.Quality = DetermineQuality(system);
        result.Equipment = GenerateEquipment(recipe, result.Quality);
        result.ExpGained = GetExpByQuality(result.Quality);
    }
    else
    {
        result.Success = false;
        result.ExpGained = 5;  // 失败安慰奖
        // 材料损失处理...
    }

    // 增加锻造师经验
    AddBlacksmithExp(system, result.ExpGained);
    system.ForgeCount++;

    return result;
}
```

## 十一、平衡性验证

### 11.1 经济消耗验证

```
假设玩家每天锻造10次：
- 平均材料消耗：约5000金币价值
- 失败损失：约1000金币
- 产出装备价值：约8000金币

净收益：约2000金币/天

结论：锻造可以小赚，但不会破坏经济平衡
高等级锻造风险更高，需要谨慎决策
```

### 11.2 成长周期验证

```
锻造师50级所需经验：约50000经验
每次锻造平均获得经验：约30经验
需要锻造次数：约1700次

每天锻造10次：需要170天（约6个月）
每天锻造20次：需要85天（约3个月）

结论：成长周期合理，提供长期追求
```
