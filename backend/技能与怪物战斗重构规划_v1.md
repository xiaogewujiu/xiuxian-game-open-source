# 技能、技能书与怪物战斗强度重构规划 v1

## 1. 目标

重构三职业技能、技能书成长和怪物战斗强度，使怪物强度同时考虑：

- 玩家等级基础属性；
- 职业属性点收益；
- 普通装备、强化和洗练；
- 高级属性、属性克制；
- 技能伤害、冷却、耗蓝和命中；
- Buff、Debuff、被动和控制；
- 普通怪、精英和首领的战斗定位。

当前代码和数据库事实：

- 玩家职业：`warrior`、`mage`、`body`；
- 当前技能模板约 85 条；
- 当前 Buff 模板约 72 条；
- 当前怪物模板 160 条；
- 玩家最多携带 6 个技能；
- 技能模板已支持三级技能链：`PreviousSkillId`、`NextSkillId`、`SkillLevel`；
- 技能模板已支持职业限制：`AllowedProfessions`；
- 技能书当前通过 `ItemSkillBookConfigs` 绑定单个技能；
- 当前没有技能书分解接口和专用碎片流程。

## 2. 已确认的产品规则

- 每个职业 10 个可掉落技能，另加 1 个基础技能；
- 每个技能包含 1、2、3 级；
- 基础技能也可以升级到 3 级；
- 三职业共 33 条技能链、99 个新技能模板；
- 一个技能对应一本技能书；
- 技能书投放不在本次固定，由后续通过管理端配置；
- 技能书分解为通用技能书碎片；
- 1 本技能书分解为 5 个通用技能书碎片；
- 1 级升 2 级消耗 5 个碎片；
- 2 级升 3 级消耗 10 个碎片；
- 重复使用已掌握技能书时自动转换为 5 个碎片；
- 现有账号清空当前技能和已掌握技能，只保留并装备本职业基础技能；
- 旧技能模板不删除，作为旧目录参考；
- 玩家前端只展示新技能；
- 管理端默认展示新技能，可切换查看旧技能和全部技能；
- 怪物复用新职业技能和现有 Buff，不新增独立怪物技能结构；
- 普通怪配置 2 个技能，精英配置 3 个技能，首领配置 4 个技能。

## 3. 新旧技能目录

在 `SkillTemplates` 增加当前/旧技能区分字段，例如：

```text
SkillCatalog = legacy / current
```

规则：

- 旧技能全部标记为 `legacy`；
- 新技能全部标记为 `current`；
- 旧技能保留原 ID、名称和配置；
- 玩家技能接口只返回 `current` 技能；
- 管理端增加“当前技能 / 旧技能 / 全部”筛选；
- 战斗运行时可以加载全部技能，保证旧配置不因缺少模板而报错。

新技能 ID：

```text
战修：1001 - 1033
法修：1101 - 1133
体修：1201 - 1233
```

每 3 个连续 ID 是一条等级链：

```text
1001 → 1002 → 1003
1级  → 2级  → 3级
```

## 4. 三职业技能设计

### 战修

基础技能：

```text
破军式
```

可掉落技能：

```text
裂甲斩、震岳击、破军连斩、横扫千军、战意燃血、断脉、追命、霸王势、铁壁反攻、绝境反击
```

定位：物理输出、破防、暴击、连击、低生命斩杀和反击。

### 法修

基础技能：

```text
引灵诀
```

可掉落技能：

```text
冰魄针、炎爆、雷引、灵泉回生、霜甲、焚心印、噬灵、星陨、净心诀、太虚禁制
```

定位：法术输出、群体伤害、灼烧、减速、易伤、回蓝、治疗和沉默。

### 体修

基础技能：

```text
锻体式
```

可掉落技能：

```text
铁壁式、裂地、镇魂吼、回元、反震、护脉、缚身、崩山、不屈、地脉震
```

定位：高生存、护盾、嘲讽、反伤、恢复、控制抵抗和破防。

## 5. 技能等级成长

每条技能链必须保持技能基本类型不变，只增强倍率和效果。

直接伤害/治疗：

```text
2级 = 1级倍率 + 0.15
3级 = 1级倍率 + 0.30
```

Buff/Debuff 采用现有 Buff 模板，必要时新增对应 Buff 变体，不新增效果类型：

```text
攻击/防御提升：10% → 15% → 20%
攻击/防御降低：10% → 15% → 20%
持续伤害：4% → 6% → 8%
护盾强度：8% → 12% → 16%
控制触发率：35% → 45% → 55%
控制持续时间：1回合 → 1回合 → 2回合
```

控制规则：

- 普通怪不能连续控制；
- 精英单次控制最多 2 回合；
- 首领不能被普通控制无限循环；
- 控制技能必须有冷却和合理触发率。

## 6. 技能书和技能书碎片

新增通用材料：

```text
技能书碎片
ItemType = Material
```

新增 30 本新技能书：

- 战修 10 本；
- 法修 10 本；
- 体修 10 本；
- 每本通过 `ItemSkillBookConfigs` 绑定对应技能的 1 级模板。

新增接口：

```http
POST /api/inventory/skill-books/decompose
```

请求：

```json
{
  "itemId": 123,
  "quantity": 1
}
```

接口要求：

- 验证物品实例属于当前玩家；
- 验证物品类型是技能书；
- 验证数量充足；
- 事务内扣除技能书并增加碎片；
- 返回分解数量和当前碎片余额；
- 不允许负数、跨玩家物品和重复扣除。

重复技能书处理：

- 玩家已掌握相同或更高等级技能时，使用技能书自动转换为 5 个碎片；
- 不再只提示“已掌握”后浪费技能书。

## 7. 技能升级

继续使用现有 `PreviousSkillId / NextSkillId / SkillLevel / UpgradeConditionsJson`。

升级条件：

```text
1级 → 2级：技能书碎片 5，玩家等级 10
2级 → 3级：技能书碎片 10，玩家等级 30
```

升级过程必须：

- 验证当前技能已掌握；
- 验证目标技能是同一技能链的下一级；
- 验证碎片和等级；
- 事务内扣除碎片；
- 替换 `OwnedSkillIdsJson` 中的旧等级技能；
- 如果旧等级技能已装备，同步替换为新等级技能；
- 3 级技能不再显示可升级。

## 8. 账号迁移

迁移时保留：

- 玩家等级和经验；
- 人物属性；
- 装备和强化；
- 道具；
- 宠物；
- 其他成长数据。

迁移技能数据：

- 清空 `SkillIdsJson`；
- 清空 `OwnedSkillIdsJson`；
- 战修写入并装备 1001；
- 法修写入并装备 1101；
- 体修写入并装备 1201；
- 旧技能模板和旧技能数据不删除，但不在玩家前端展示。

新玩家注册时直接获得本职业基础技能。

## 9. 怪物技能配置

怪物使用新技能 ID和现有 Buff：

```text
普通怪：2个技能，主要使用1级技能
精英怪：3个技能，使用1~2级技能
首领：4个技能，使用2~3级技能，并配置1~2个被动Buff
```

职业对应：

- 物理怪优先使用战修技能；
- 法术怪优先使用法修技能；
- 防御型怪优先使用体修技能；
- 材料守卫使用与材料主题对应的攻击、控制或防御技能；
- 精英至少有一个明确战斗机制；
- 首领必须包含输出、防御、控制或恢复中的至少三类能力。

阶段开放节奏：

```text
S01：基础技能 + 第1个非基础技能
S02：基础技能 + 前2个非基础技能
S03：基础技能 + 前3个非基础技能
……
S10：完整技能池
```

## 10. 怪物属性模型

怪物属性不能再只按固定倍率增长，必须以同等级玩家实际战斗底板为参考：

```text
等级基础属性
+ 职业属性点收益
+ 普通等级装备
+ 默认高级属性
+ 必要的常驻Buff
```

当前人物基础数据参考：

| 等级 | 生命 | 灵力 | 攻击 | 防御 | 速度 |
|---:|---:|---:|---:|---:|---:|
| 1 | 420 | 180 | 42 | 20 | 18 |
| 10 | 1123 | 441 | 93 | 52 | 28 |
| 20 | 2075 | 835 | 166 | 99 | 39 |
| 30 | 3207 | 1339 | 254 | 157 | 51 |
| 50 | 6011 | 2677 | 479 | 311 | 74 |
| 70 | 9535 | 4455 | 768 | 513 | 96 |
| 90 | 13779 | 6673 | 1121 | 762 | 119 |
| 100 | 16171 | 7947 | 1321 | 905 | 131 |

普通怪目标：

```text
攻击型：生命75%~90%，主攻击85%~95%，主防御80%~90%，速度95%~105%
防御型：生命90%~105%，攻击70%~85%，防御100%~115%，速度80%~95%
法术型：生命70%~85%，主法攻90%~100%，法防85%~100%，速度100%~110%
```

精英目标：

```text
生命130%~160%
主攻击100%~115%
主防御100%~115%
速度95%~110%
```

首领目标：

```text
生命220%~280%
主攻击110%~125%
主防御110%~125%
速度100%~115%
```

高级属性参考：

```text
普通怪：命中93%~96%，闪避3%~6%，暴击3%~8%，连击0%~3%，反击0%~3%
精英：命中95%~98%，闪避5%~9%，暴击8%~14%，连击3%~7%，反击3%~8%
首领：命中97%~99%，闪避6%~12%，暴击10%~18%，连击5%~10%，反击5%~12%
```

强度预算必须按技能实际期望伤害修正：

```text
期望每回合伤害 = 普攻期望伤害 + 技能倍率期望伤害 + Buff收益 + 控制收益
```

拥有控制、恢复、护盾、易伤、反伤或群攻的怪物，要降低其静态攻击或生命，不能技能和面板同时拉满。

## 11. 实施顺序

1. 增加技能目录字段和前后端筛选；
2. 建立 99 个新技能模板和 33 条三级技能链；
3. 建立新基础技能和 30 本技能书；
4. 建立通用技能书碎片；
5. 实现技能书分解接口；
6. 实现重复技能书自动转碎片；
7. 修改技能升级消耗和升级校验；
8. 迁移现有账号到本职业基础技能；
9. 重新配置 160 个怪物技能和被动 Buff；
10. 重新计算 160 个怪物的属性区间；
11. 配置技能书掉落入口，但不擅自决定具体投放；
12. 完成战斗、接口、管理端和数据完整性测试。

## 12. 验收标准

技能：

- 新技能共 99 条；
- 每条技能链长度为 3；
- 三职业限制正确；
- 基础技能可直接获得；
- 新技能在玩家前端可见；
- 旧技能在玩家前端不可见；
- 管理端可以切换查看新旧技能。

技能书：

- 一本技能书只绑定一个技能；
- 分解 1 本获得 5 片；
- 重复技能书自动获得 5 片；
- 升级正确消耗 5/10 片；
- 分解和升级具有事务原子性。

怪物：

- 普通怪 2 技能、精英 3 技能、首领 4 技能；
- 所有怪物技能 ID 都存在；
- 技能等级符合阶段；
- Buff ID 全部存在；
- 不出现普通怪一击秒杀同级角色；
- 不出现首领无限控制；
- 技能不足蓝量时不会永久空过。

战斗目标：

```text
普通怪：同级角色约2~5回合解决
精英怪：同级角色约5~8回合解决
首领：同级角色约8~14回合解决
```

测试等级：

```text
1、10、20、30、50、70、90、100
```

测试职业：

```text
战修、法修、体修
```

测试情况：

- 无宠物；
- 带普通宠物；
- 无技能对照；
- 有技能；
- 有 Buff；
- 有装备强化和属性点。

## 13. 约束

- 旧技能模板不删除；
- 旧 Buff 不删除；
- 不修改地图、道具、装备、怪物等无关字段；
- 不改变原有 ID 的业务含义；
- 新增代码只限技能、背包、账号技能、管理端和怪物战斗配置相关范围；
- 不擅自决定技能书的具体掉落投放；
- 所有数据库改动先备份；
- 完成后启动三个站点并验证。
