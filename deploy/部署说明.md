# 修仙问道 Docker 部署说明

## 目录

```text
deploy/
├── api/                    .NET 发布文件和 Data/game-dev.db
├── game/                   游戏端生产静态文件
├── admin/                  管理端生产静态文件
├── api.Dockerfile
├── game.nginx.conf
├── admin.nginx.conf
└── docker-compose.yml
```

## 服务器要求

- Docker
- Docker Compose（新版 Docker 使用 `docker compose`）
- 对外放行 80、5176、5247 端口

## 上传

在本地项目目录执行：

```bash
scp -r deploy 用户名@服务器IP:/opt/xiuxian/
```

如果 Windows 没有 `scp`，可以使用 WinSCP，把整个 `deploy` 文件夹上传到服务器的 `/opt/xiuxian/`。

## 启动

```bash
cd /opt/xiuxian/deploy
docker compose up -d --build
docker compose ps
docker compose logs -f api
```

访问地址：

- 游戏端：`http://服务器IP/`
- 管理端：`http://服务器IP:5176/`
- 后端 Swagger：`http://服务器IP:5247/swagger/index.html`

## 更新

本地重新发布并上传 `api`、`game`、`admin` 三个目录后，在服务器执行：

```bash
cd /opt/xiuxian/deploy
docker compose up -d --build
```

## 停止与查看

```bash
docker compose stop
docker compose ps
docker compose logs --tail=200 api
```

## 注意事项

- `api/Data/game-dev.db` 是当前基准数据库，必须保留。
- `api/Data` 和 `api/wwwroot/uploads` 已挂载为持久化目录。
- 首次部署前建议复制一份 `api/Data/game-dev.db` 作为服务器备份。
- 如果服务器 80 端口已被占用，将 `docker-compose.yml` 中游戏端的 `80:80` 改为例如 `8080:80`，然后访问 `http://服务器IP:8080/`。
